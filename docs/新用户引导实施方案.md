# v1.1 新用户引导实施方案

## 问题与目标

现有欢迎页直接进入资金试算或登录，首页同时呈现消费、资金、练习和推荐；新用户缺少理解产品价值与操作先后的短路径。已有12题自评不适合作为必经引导。

## 实施计划

1. 新增轻量的三步前置体验：示例消费的钱币展开、说明生活安排、选择第一个实际操作。避免逐个功能讲解，支持跳过、返回与继续。
2. 游客从欢迎页进入；学生首页仅在成功确认无账单和成长记录、且本机未完成引导时自动引导。既有用户可从首页主动重看，学校端和管理员端不接入。
3. 复用钱币呈现，加入短暂入场与分步过渡，尊重减弱动效。无新依赖，不写入示例账单，不默认授权个人数据。引导状态按本机账号保存，存储不可用时仍可完成本次操作。
4. 检查首次进入、跳过、继续、重看、账户切换、读取失败、手机与桌面布局、键盘焦点及减弱动效；运行相关回归与生产构建。
5. 更新VERSION、CHANGELOG、README及验收记录，以v1.1正常同步代码和标签。保留开关回退。

## 验收边界

引导完成不等于已完成记账或取得教育效果；自动触发以成功读取的空数据为依据，不把读取失败当新账号。状态仅属于本机浏览器，不声称跨设备同步。新增入口可以关闭，原问卷、账本与学习流程保留。

## 实施与验收结果

2026年11月8日完成v1.1实现。欢迎页新增入口，学生首页按成功读取的空数据自动进入，首页保留重看入口。独立引导页按角色返回各自工作区；游客完成后登录可直接进入记账或首页，避免再次自动引导。

进度记录只包含步骤与状态，按本机账号隔离；持久存储不可用时以当前标签页内存继续操作。跳过或完成不再自动出现，手动重看从第一步开始；未完成可从原步骤继续。没有自动填写个人资料或保存演示账单。

- 前端全量42套、273项测试通过，覆盖空数据判定、原首页与问卷回归、完成、跳过、继续、账号隔离、浏览器存储受限、游客及角色分离。
- 8个隔离浏览器场景通过：390px与1280px各验证游客完整体验和登录记账、新账号自动进入与恢复进度、已有记录不自动进入、读取失败不自动进入。检查示例无API写入、页面无异常、金额展示无横向溢出、步骤标题焦点及减弱动效。
- 生产构建成功，已有主包体积提示仍在。本轮没有后端业务改动，未重复运行后端测试。
- 动效为短暂钱币入场与步骤过渡，尊重`prefers-reduced-motion`；示例图形复用现有面额组件，不增加依赖。

关闭方法：设置`REACT_APP_PRODUCT_GUIDE=false`并重启前端或重新构建。引导状态不改变财务记录；代码可回退至v1.0。浏览器数据被清理或更换设备后可能再次出现，此版本尚未做跨设备同步，使用效果仍需真实用户试用验证。
