# AIC 技术升级与验证说明

## 定位与实际实现

青盈面向大学生金融素养自主学习，以预算、取舍、不确定性和风险理解为教学目标。此次实现属于可解释规则与大模型结合的原型，不宣称提出新的基础模型算法，也不宣称已经证明教学有效。

- 聊天：中文双字词片段检索 → 用户授权后读取账户资料及消费记录 → 决策引擎计算 → 大模型解释 → 结构与引用校验 → 服务端附上数值和原始摘录。
- 练习：四主题、每主题基础/迁移各一道，共八道客观情境题。答案在服务端判定；保留每次作答，但推荐只使用当前题库版本中每道题最近一次回答。先复习答错题，再补充尚未回答的主题证据。用户可主动选择其他题。
- 原有七次开放练习保留；不通过关键词给自由文本评分，不把重复答题计为新的迁移证据。

入口：理财成长 → 七天练习顶部的新情境卡片；AI 教练 → 勾选资料与消费汇总授权后，可填写本次试算金额。金额只试算，不记账。

## 数据与失败处理

知识检索读取与用户知识页一致的已发布文章，不绕过管理员编辑或删除，也不自动导入样例。未导入或匹配不足时明确提示没有证据。知识库不可用时显式降级。账户资料读取失败则停止本轮，避免假装已读取。消费原始备注、商户等不作为计算证据发送给模型，仅发送汇总；另有用户明确授权的资料和最近五条学习记录。

计算始终标注记录区间、数量和完整性未知。零记录不估算余额；跨度不足三十天、无效记录或读取达到上限不推算延迟。未来记录不纳入统计。未来开支未扣除；未对多目标做资金分配；目标延迟只是“此金额原本用于未完成储蓄目标”的情境估算，不是特定目标预测。所有计算均不涉及投资收益。

模型必须返回 explanation/source_ids，校验 JSON、引用编号、链接及常见数字表达；不通过则用固定解释替代。数值由服务端展示。该校验不能证明语义正确，也不能覆盖所有隐晦数量表达。展示的摘录是检索材料，不表示模型的每个句子均已被证实；仍需人工评估事实支持度。知识来源日期未标注时如实显示。模型调用失败仍返回失败，不伪造 AI 回复。

情境记录使用现有按账户隔离的 learning_entries，无新增数据库表。旧题库版本记录不会加入当前推荐。题库答案仍可从开源代码得知，所以这些题适用于形成性学习，不适用于考试或独立成效测量。

## 已运行的离线开发评测

运行 `.venv/Scripts/python.exe backend/evaluation/run_offline.py`，结果保存到 `docs/AIC_OFFLINE_RESULTS.json`。

增加正文相关性门槛后的开发集结果：十一条有目标文章的检索问题，Top-3 命中十条；一条无关问题正确弃答；六项计算/推荐基准检查通过。未命中项为“借新还旧有什么危险”；正文使用“用新贷款解决旧贷款”，当前词面检索不能可靠处理这一同义改写，已保留该失败案例。语料和题目文件的 SHA-256 保存在报告中。

这是人工编写、接近文章标题的开发集，只验证链路能工作。不是独立盲测，也不是与通用大模型的性能对比。报告用合成数据，未连接个人账户或调用真实模型。

## 模型对照与消融

`backend/evaluation/run_model_comparison.py` 提供显式开启的真实 API 评测，默认不发送请求。

```powershell
.\.venv\Scripts\python.exe backend/evaluation/run_model_comparison.py --run-api
```

使用 `.env.local` 中现有密钥和可选 `ZHIPUAI_MODEL`；会调用服务商并可能消耗额度。五组分别是通用提示、当前旧提示策略、增强系统、移除知识检索、移除计算。各组使用同一模型、采样参数与合成原始资料；四个案例共二十次请求。保留响应、失败、格式回退、耗时、token 用量和提示词摘要，不自动赋予质量分数。输出按请求逐次保存，单次失败不会丢失前面结果。旧提示组是受控策略基线，不是旧产品完整线上复现；增强评测提示也不是生产调用的逐字回放。

正式实验应另外建立不参与调参的题集，包括同义改写、遗漏资料、多轮指代、退款、未来开支、错误来源、注入文本和不同收入情境。按用户隔离训练/开发/测试记录。重复采样并固定模型版本，报告失败率和回退率，不仅保留成功回答。

两名具备相关知识的评审在隐藏组别后独立评价：数值正确性、引用是否真的支持结论、关键条件识别、教学引导、用户自主性。对分歧复核并报告一致性。自由文本不能让生成它的同一模型独立充当裁判。测试前确定量表与主要指标。

## 真实试用方案（尚未开展）

先邀请五至十位自愿参与者发现可用性问题；这一阶段不做因果结论。说明数据用途、记录范围、退出方式、保留时间和负责联系人，经同意后使用研究编号。不要在报告中导出真实账户、账单备注或聊天原文。

后续比较固定教学与自适应教学时，保证学习内容和时长接近，预先确定分组方法及样本量依据。前后测及延迟测使用不在练习题库中的等难度新情境。主要结果为关键条件识别、取舍解释、备用方案与迁移表现；同时记录负担、压力、退出和缺失数据。省钱金额和完成次数不作为能力证明。

记录模板见 `backend/evaluation/pilot_template.csv`。它是空表，不含真实参与者，也不触发任何自动研究上传。仅收集研究必要数据；真实参与者招募、知情同意和专业评分仍需团队执行。

## 后续技术优先级

1. 扩充经专业人员审核的独立题目与同义检索测试，检查是否过于依赖标题。
2. 收集足够真实答题证据后，比较当前规则基线与概率学习状态模型；不把经验比例包装成校准概率。
3. 加入完整记账区间声明、缺失记录处理与个人历史基线，再验证行为模式阈值。当前旧行为模式引擎的固定阈值没有改成学习模型。
4. 开展真实服务商和目标数据库联调；离线测试中的模拟不能替代生产验收。

## 本次真实接口试跑记录

使用纯合成数据完成五组 × 四个场景，共二十次真实调用，均返回成功，总 token 用量 13,849。原始结果保存在 `docs/AIC_MODEL_RUN.json`，人工评分字段保持空值，没有据此生成教学效果结论。

这轮运行启动于正文相关性门槛和 JSON 代码块兼容修复之前，属于排错试跑，不是最终版本性能验收。原校验在十二次增强/消融响应中回退十一次；检查发现这些响应均带 Markdown JSON 代码块，其中三条试算解释还包含数字。现已支持单个完整 JSON 代码块，并用测试确认其中的数字表达仍被拦截。未把旧响应的结果改写成修复后的“成功率”，也未将不同提示词长度造成的耗时差异解读为模型性能提升。

真实接口试跑支持“接口可连接”的结论；最终回答质量、事实支持度、同义改写召回和教学成效仍需独立评测。后续运行会使用修复后的代码。
