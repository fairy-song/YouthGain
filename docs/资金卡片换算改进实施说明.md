# 资金卡片换算改进实施说明

日期：2026-10-28。范围：现有首页资金卡片的可展开换算展示。

## 已实施

- 首页“本月可用剩余”下增加“查看每日均分”，主动展开后显示月金额、剩余天数（含当天）、日均参考与一次钱币拆分动效。
- 原余额、资金口径、账本入口和结转确认保留；账本复用卡片默认不开启换算。
- 只用已有资金快照派生参考值，金额按分均分并向下保留两位；不写入交易、预算或储蓄数据。
- 现有资金响应补充同一快照的 `timezone`，无需新接口或数据库迁移。前后端都需要运行本次代码后，正常快照才具备完整换算信息。
- 未确认值、异常金额、零值、负值、非法日期、跨日和个人时区分别处理；可见页面每分钟检查日期，后台恢复和主动展开也检查。
- 同日资金刷新保持展开区域，终止旧动画；跨日隐藏旧派生结果，刷新失败沿用首页现有错误和重试界面。
- 支持键盘展开、可见焦点、读屏公式和减少动态效果设置。

## 回退方式

### 只关闭展示

在项目本地前端配置中设置 `REACT_APP_DAILY_FUNDS_BREAKDOWN=false`，重启开发服务或重新构建前端。不要覆盖原有环境配置文件。

关闭后隐藏换算入口及增强样式，保留原资金卡片；后端新增的时区元数据可以保留。该开关在构建时读取，不是部署后即时切换的远程开关。

### 完整恢复本次代码

改动前原文件位于 `tmp/funds-breakdown-20261028-before/`，其中 `rollback-manifest.json` 记录13个相关代码/测试文件的改前及改后指纹。

在项目根目录先预览：

```powershell
.venv/Scripts/python.exe scripts/rollback_funds_breakdown.py
```

确认清单后恢复：

```powershell
.venv/Scripts/python.exe scripts/rollback_funds_breakdown.py --apply
```

脚本先验证全部文件及备份，再进行恢复。只处理清单中的本次源代码与测试；新文件在留存副本后移出当前实现，原文件恢复到改动前。当前版本会归档到备份目录下的 `rolled-back-*`，便于重新取回。

如果文件在实施后又被修改，脚本会拒绝覆盖，需先合并或另外保存后续修改；不会自动强制恢复。设计文档、实施说明及回退脚本本身保留，数据库和用户数据不参与回退。备份位于被 Git 忽略的 `tmp/`，仅属于本机；清理临时文件或转移项目时，应一并保留该备份目录。

回退后重启相应服务；静态发布需要重新构建。未使用 `git reset` 或覆盖已有部署目录。
