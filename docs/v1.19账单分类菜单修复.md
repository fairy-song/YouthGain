# v1.19 账单预览分类菜单修复

问题：点击预览行分类后菜单闪现并关闭。真实 Edge 浏览器复现：打开后经过焦点移动，菜单已不在 DOM。

原因：Overlay 默认将菜单放到 body，位于导入 Modal 焦点边界之外。菜单选项自动聚焦触发 Modal 拉回焦点，菜单 onBlur 继而关闭。

修复：将菜单挂到触发器所属 dialog，仍位于表格滚动容器外；不关闭弹窗焦点保护，不改变金额、分类选项或确认导入流程。

验收：手机与桌面点击菜单保持打开、选择系统及自定义分类、键盘和 Esc、删除确认取消后恢复；菜单不得被表格裁剪，选择本身不得导入账单。无数据迁移，可撤销发布提交回退。


验证：修复前浏览器断言菜单消失；修复后 390px/1280px Edge 均通过点击稳定打开、系统和自定义分类选择、键盘和 Esc、重新打开、嵌套删除确认取消后继续选择。已查看手机截图，菜单不被表格裁剪，未提交导入，未改真实账单。

导入弹窗 22 项、账本和补录 33 项前端检查以及导入/分类 20 项后端检查通过。生产构建成功（主包 560.8 kB gzip，既有体积提示仍在）。全部 API 为隔离模拟，脚本 scripts/test-import-category.cjs 接受 Playwright 模块和浏览器路径，默认读取 build-verification。
