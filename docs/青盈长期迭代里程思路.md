# 青盈长期迭代里程思路

核对日期：2026-10-12。本文维护产品方向、待办和验收门槛；当前实现以[功能与技术文档](目前版本实现的功能及其对应的技术.md)为准。

## 1. 产品主线

服务大学生财商学习：用本人真实记录建立生活情境，让用户通过小练习理解预算、取舍、不确定性和风险。

```text
消费记录 → 清洗及统一收支口径 → 可解释情境特征
问卷自述 + 答题证据 → 当前学习需求
情境与需求匹配 → 一步互动练习 → 反馈 → 间隔复习 → 独立效果评估
```

PCA 与聚类是可选实验，不是流程成立的前提。消费情境画像决定练习是否贴近生活，学习画像决定哪些知识点需要巩固。

产品约束：一次只强调一个任务；不把少花钱作为统一正确答案；用户能换题、回看、退出。自评、记录量、点击和积分不能包装成财商能力分数。

## 3. 下一里程碑：可用性和数据一致性

按以下顺序处理，不同时扩展新模型与新平台：

1. **播客跳转故障。** 在实际浏览器和部署环境复现，核对接口 `episode_url`、渲染链接、遮挡层与导航拦截。验收需桌面/手机真实点击到对应单集；外部不可访问时有提示。
2. **自定义分类删除。** 解决后端测试临时目录权限问题并重跑相关断言；重启加载最新接口后用隔离账户联调。覆盖取消后菜单保持、删除不误选、两处列表同步、历史保留、未提交选择清理与账户隔离。
3. **账本一致性联调。** 在实际存储后端验收超过 50 笔、跨月退款、手动收入、单边导入、修改撤销及汇总失败。摘要与分类净额之和一致，不把预算假设写成收入。
4. **教练事实边界。** 当前输出只检查格式。建立独立数值和引用验证；缺材料或调用失败时提供固定提示/明确失败。修正后台提示词保存与当前聊天未接通的问题，再声称配置生效。
5. **发布与恢复。** 明确前后端版本、依赖与配置，补发布验收和备份恢复验证；补语音接口认证、调用配额与输入限制。本地 JSON、SQLite 的实现不能直接包装成多主机高并发方案。

## 4. 内容质量与持续学习

### 4.1 题库审核

按生活费、退款、固定费用、目标、分期和诈骗场景组织。每题保留能力点、难度、前置步骤、数字答案、解释、来源、版本、审核人、日期和撤回状态。

发布流程：编写 `draft` → 小范围试用 `pilot` → 独立复核 `approved`；发现问题转 `withdrawn`。工作表只是辅助，填写表格不会自动发布。

先审核现有 32 道，再补题量。逐题复算手续费、退款和期限，核对国内适用性与来源使用依据。开放题按识别约束、解释理由和备用方案反馈，不用关键词硬判对错；不复用练习原题证明学习效果。

### 4.2 低负担界面

每屏一个问题、一个主操作。答后先给一两句反馈，计算和资料按需展开；允许上一步、换情境、今天结束。统一控件、焦点与状态提示，窄屏不遮挡按钮，遵守减少动效设置。

现有青苗鼹只在今天练习卡右下角，后续不扩散到全站或增加遮挡。首页专属 IP 与动效需单独设计稿，不把早期未做 IP 的规划当作当前事实。

### 4.3 B2 卡内 AI 教练

次级入口打开侧栏或手机底部面板。题前给提示而非答案，题后可换种说法、举新例子、追问遗漏条件。关闭后保留草稿、选项、反馈和步骤；AI 不自动提交、推进或改分。

默认上下文只有题号/版本、情境、当前步骤、知识点与主动问题；提交后才增加确定性反馈。向外部发送个人汇总仍须独立选择。服务故障不阻断固定练习。

### 4.4 习惯引导

先验证一个具体行动及后续复盘。将现有个人规则文本升级为可检查的 If–Then 触发规则是待办，尚无自动触发引擎。提醒由用户控制频率，不以连续打卡施压，不以消费下降或完成次数评价学习。

## 5. 每日一期音频的升级

保留「一期一条」与每日最多一条，先扩大可复核目录，再升级匹配：

1. 维护公开简介、链接、日期、主题、难度和人工质量记录；简介匹配不替代抽听。
2. 修复跳转，配置到期同步与失效监测，复核来源变化。RSS 新单集发现另做待审核入口，不能把现有描述同步说成自动发布。
3. 以主题规则、字符哈希向量为基线，对比中文语义嵌入，检查同义改写、重复、冷启动与无候选。
4. 固定目录和用户切分，报告相关性、理由正确性、覆盖与重复，不只报告点击率。
5. 平台接入另核对公开接口、授权与条款；无接入条件时继续维护公开元数据。

## 6. 算法升级条件

### 6.1 特征工程与可选降维

先统一退款、转账、缺失与时间窗口，保留覆盖标记。候选特征为类别比例、频次、固定费用、预算余地、收支时间差、目标与近期义务，只取能核对的变量。

跨用户矩阵以用户/固定时间窗为样本，不能把当前个人周样本当作群体画像。统计量只在训练集拟合；金额比较对数/比例变换，少量业务交互项单独验证，不盲目展开全部多项式。

PCA 排序主成分的解释方差，不直接把原始类别按重要性删除。方差小但与债务或风险有关的变量可能要保留；是否减少成本、稳定分群或改善推荐需实测。

### 6.2 聚类与 UMAP

跨用户聚类不是必选。取得对应授权、足量覆盖数据后，在离线环境对比原始特征与 PCA 后的 K-means、GMM、密度聚类，检查跨时间/重采样稳定性与下游学习收益。

UMAP 用于非线性探索、可视化实验；二维距离不等于人格或能力。固定随机种子并报告参数敏感性，不因图上看见簇就生成教育标签。无可靠收益则维持个人规则推荐。

### 6.3 推荐与复习

先对照主题基线、现有规则、移除消费线索、移除答题证据，再比较内容向量召回。有足够知识点序列时评估 BKT；DKT、排序模型和上下文 Bandit 后置。

当前复习是 2/7/14 天规则，不保证自动换题。后续增加不同数字/条件的同能力情境，比较作答和延迟保持；复杂调度是否替换需独立验证。

切分按用户、时间和情境族隔离，避免相同题变体进入训练与测验两边。复杂模型只增加点击、题量或停留而未改善理解时，不替换基线。

## 7. C/D 验证门槛

先邀请 5–10 位自愿学生执行真实任务，记录独立完成、阅读负担、退出与误解；每轮先修两三个重复问题。可用性试用不做教学因果结论。

正式对照前确定平行测验、主要指标、分组、样本量依据和测量间隔。前测、后测、延迟测使用不同且不在日常练习中的审核情境；开放题由独立评分者复核。

| 类型 | 指标与用途 |
| --- | --- |
| 体验 | 首题启动、问卷中断点、难懂文字、阅读负担、再次使用原因 |
| 学习 | 条件识别、金额核对、取舍解释、备用方案、未见情境迁移、延迟保持 |
| 过程/行为 | 自愿记录与复盘、点击、练习完成；解释参与过程 |
| 工程 | 金额正确、账户隔离、失败/回退率、延迟、版本与引用可追溯 |

报告缺失、退出、样本偏差和不确定性。每组 10 个前后测配对只是现有描述程序的输出门槛，不是正式样本量论证。真实模型试跑、历史功能测试与合成命中率均不能证明学习提升。

## 8. 长期方向与暂停项

先解决数据导出、保留期限、删除请求、恢复与外部 AI 数据透明度，再评估浏览器本地特征、PWA/离线练习、低带宽版本。这些是后续选项，未认定为完整现有能力。

学校研究继续暂停，个人学习试用不等于启用学校端。恢复前需核对统一账本口径、独立隐私审查、项目权限、同意、预算、保存期限与运行环境。已有中央差分隐私依赖可信后端，不能称服务器看不到明细。

联邦学习、安全聚合、端侧训练和群体 PCA 尚未实现；仅在明确多方训练问题、参与条件和泄露威胁后评估。联邦学习不是自动隐私保证。

开放课程资源、可替换内容/模型模块、跨生活情境迁移可作为扩展方向，匿名朋辈或社交功能后置。当前不做金融产品导流、收益承诺或未验证的心智评分。运营成本先记录服务器、审核工时、模型调用/失败/重试量，不沿用旧稿的用户规模、成本、盈利预测。
