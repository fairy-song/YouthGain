# 全站交互检查与修复记录

检查日期：2026-10-29。环境：本地开发服务；写入操作使用演示账户。

## 实施计划

1. 启动前后端，建立页面及可点击控件清单。
2. 用演示账户模拟导航、提交、取消、筛选、分页、错误输入及刷新恢复；核对实际保存结果。
3. 覆盖访客入口、首页、账本、学习、教练、知识库、个人资料、研究参与及管理员页面。
4. 按阻断功能、数据错误、交互不便排序，逐项记录复现步骤与修复结果。
5. 修改前保存本轮文件快照，不覆盖此前工作；执行相关测试及构建，再回到运行页面复查。

## 检查边界

- 不修改真实账户的账单、身份或权限。
- 麦克风、外部邮件及外部付款仅检查入口及失败反馈，不产生真实对外操作。
- 每项注明实际点击、自动化验证或静态检查，未验证不记为通过。

| 手机布局 | 手机窄屏下导航、填写账单、保存及钱币展示；检查页面无整体横向溢出 | 不等同于所有实体手机与浏览器均已验证 |
