# 一周试用清单

邀请 5–10 位自愿参与的大学生，使用已有功能；不收集密码、账户凭证或原始敏感账单。

## 操作任务

1. 填写月生活费并核对实际余额，说明两个金额有什么区别。
2. 比较一笔真实消费，不保存也能获得结果；保存计划后确认账本未增加支出。
3. 手动或语音记账，确认本月预算和估算余额变化。
4. 一周后完成两个问题的复盘，并回看历史记录。

## 观察记录

记录任务是否独立完成、需要解释的步骤、看不懂的金额、不愿填写的内容、保存或刷新错误、是否愿意再次使用及原因。
避免只问“好不好用”；请用户描述最近一次真实选择，以及页面实际帮到了哪一步。

## 下一轮修改

每轮优先修复两三个重复出现的问题。参与次数只作为过程数据，不作为学习效果证明。试用结果由参与者反馈后再填写，不预设成功结论。
