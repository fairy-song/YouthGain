# 财务口径与推荐 v2 实施计划

1. 新增 SQLite 月度结转与储蓄划拨账目，保留事件追加和每日唯一约束。
2. 根据用户确认，可用剩余 = 上月结转 + 实际收入 − 净支出 − 本月净储蓄划拨；锁定总额独立保存。
3. 接入目标新增、存入、撤销及释放，使用幂等与事务保证内部划拨不计收入支出。
4. 财务快照读取统一资金口径及 goal_planner，保存不可变快照；历史推理只读取快照，禁止用当前目标重建历史。
5. 完善新用户与来源异常降级、追加事件、协议 schema、模板解释扩展入口。
6. 账本保留一个“本月可用剩余”字段，加入结转设置、储蓄锁定资金与划拨说明。
7. 按 SQL、服务、路由、前端、配置顺序交付工程代码及接口定义，验证资金守恒、时间隔离、幂等、并发和回退。

本文件是早期资金口径改造计划，当时不训练 HSTU。后续 AI 升级已经补齐网络、训练与推理，见 [AI 教练与 HSTU 实现说明](AI教练与HSTU实现说明.md)。
