# 自动知识库与自适应辅导实施记录

2026-11-07；基线 b574e18。依据《青盈AI论文调研与自动知识库方案-20261107》。

## 实施计划

1. 建立容量统计和可配置的活跃文档／片段配额；公开列表分页完整读取，区分存量、切分量、持久索引量与尚未压测容量。
2. 持久保存公共知识片段与向量，按内容和模型版本增量更新，原子切换索引快照；撤回内容不得因旧缓存继续用于回答。
3. 新增自动筛选台账：来源硬条件、内容规则、可用时模型语义判断、异常隔离和有限自动发布。现有来源默认保留人工发布策略，管理员可在确认使用范围后启用；没有校准材料的语义筛选不冒充训练完成的模型。
4. 新增教练缺口感知决策：辨别个人信息缺项、公共依据缺失和计算条件，模型可用时输出受校验的结构化选择，不可用时明确降级；支持追问、补检、计算事实解释和暂缓。
5. 管理端展示容量、自动筛选原因与来源策略；学生端继续保持简单阅读和辅导路径，三端权限独立。
6. 使用隔离数据验证容量、重复与变更、撤回、模型异常、提示注入、分页和辅导边界；完成构建、浏览器验收和本地备份／回退说明。

## 边界

不扩充虚假文章，不更改真实账单，不把工程测试写作教育效果或算法优势。原始资料和既有发布历史保留。首版配额目标为 1,000 篇与 20,000 个片段，实测容量另行报告；不声称已训练强化学习控制器或完成专家标注。

## 已落地的使用路径

学生继续使用原来的知识页和 AI 教练，无需新增操作入口。管理员进入 `/#/admin/login`，登录后打开“知识库管理”（`/#/admin/knowledge`），可查看实际容量、筛选依据、版本变化和来源策略。

```text
可信来源按计划检查 → 内容指纹去重 → 来源/日期/地区/内容规则
                                ↓
                    AI 分类 + 必须对应原文的摘录
                                ↓
          来源允许自动发布且全部通过 → 配额校验 → 发布与持久索引
          不确定/模型异常/政策费用/正文变更 → 复核队列

用户问题 → 已有检索与程序事实 → 缺口判断与受约束的模型动作选择
                             ├─ 缺个人条件：追问，允许只讨论通用方法
                             ├─ 缺公共依据：最多再检索一次
                             ├─ 有计算事实：解释已有计算
                             └─ 回答或暂缓具体结论，并展示依据
```

1. **自动筛选**：后台处理新增及到期的待处理版本；记录模型分类、原文摘录、规则原因、处理时间和发布者。完全重复的正文即使更换标题也会提示排除，疑似注入指令和超长正文进入复核。建议排除不删除原始版本，管理员可以纠正。
2. **有限自动发布**：来源设置中确认内容使用范围后，可启用“合格基础内容自动发布”。仅对符合全部条件的中国内地基础教育新内容生效；费用、利率、制度、产品、冲突、缺日期和既有正文更新仍需复核。现有来源保持人工发布策略，自动筛选已经启用。
3. **可确定的容量**：显示完整库存、全文字符数、字节数、片段数、配额与索引状态。公开目录每页最多 200 篇，前端读取全部分页；加载期间版本变更则重新读取，避免拼接不同快照。
4. **持久索引**：公共全文片段及内容寻址的向量写入 SQLite；正文或模型文件版本变化时重新处理，撤回后不再检索该内容。磁盘索引异常时，以当前公开内容即时执行关键词检索，不恢复已撤回的旧结果。
5. **自适应辅导**：模型输出结构化动作，程序校验允许的动作和缺失字段；公共知识不能填充个人余额，金额继续由已有程序事实支持。模型不可用时回退规则，页面可查看本轮方式。动作 `calculate` 表示解释已计算事实，不是新增自动执行工具。

## 配置与回退

默认配置已写入 `.env.example`，本轮没有改动个人资料或账单。切换配置后重启后端：

| 配置 | 用途 |
| --- | --- |
| `KNOWLEDGE_MAX_ARTICLES` / `KNOWLEDGE_MAX_PASSAGES` | 发布配额；达到上限留待处理，不丢弃采集正文 |
| `KNOWLEDGE_SCREENING_ENABLED=false` | 关闭新自动筛选，保留原人工审核发布 |
| `KNOWLEDGE_SCREENING_AI=false` | 仅执行规则检查，停止本功能的远程模型调用 |
| `KNOWLEDGE_PERSISTENT_INDEX=false` | 使用内存检索，保留磁盘资料供恢复 |
| `COACH_ADAPTIVE_ENABLED=false` | 恢复原教练回答路径，保留既有事实计算与回答检查 |
| `KNOWLEDGE_SCREENING_MODEL` / `COACH_POLICY_MODEL` | 覆盖模型；留空沿用 `ZHIPUAI_MODEL` |

变更前的 SQLite 一致备份及本地开发记录副本位于 `tmp/knowledge-v3-before/`，不提交仓库。通常用开关即可回退，不需要还原数据；如必须恢复数据库，应先停止对应服务并另存恢复前现状，避免覆盖更新后的资料。新索引可重建，原始文章与版本历史不依赖它。代码使用单独的 Git 分支保存，便于审查、修改和撤销本轮提交；不覆盖其他未提交成果。

## 尚未完成、不得在申报书中写成既成成果

- **尚未训练新算法**：这版是模型推理、现有检索方法与工程约束的组合原型。研究创新应后续用对照实验说明何种缺口策略带来何种改善。
- **尚未校准自动筛选质量**：需建设独立的专家标注集，分别报告误收、误拒、引用一致性、地区与时效判定；真实调用成功不等于已证明筛选准确率。
- **尚无真实教育效果结论**：需招募自愿试用者，检验理财意识与实际行动变化；不以算术题正确率代替消费行为改善。
- 当前只有规范化正文的精确去重，未实现近义改写去重、跨来源事实冲突验证；模型的 `conflict` 是复核信号，不是完成事实核查的证明。
- 当前是单机 SQLite 协调与完整矩阵检索，未验证多实例写入协调及高并发吞吐；管理台展示最近 300 个版本，完整历史仍保留在数据库，尚未提供历史翻页。
- 采集受可信来源目录、网页可访问性和更新周期约束，不保证实时覆盖整个互联网。现有来源自动发布数为 0；管理员确认使用范围并开启策略后才会自动发布合格资料，其余继续复核。
